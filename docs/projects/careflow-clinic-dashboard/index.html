Project overview

진료팀이 환자 흐름과 운영 지표를 빠르게 확인하고 대응할 수 있도록 만든 클리닉 운영 대시보드입니다.

Challenge

서로 다른 도구에 흩어진 예약·대기·진료 데이터를 운영자가 빠르게 종합하기 어려웠습니다.

Approach

역할별 의사결정 순간을 기준으로 정보를 재구성하고, 예외 상황을 가장 먼저 발견할 수 있는 우선순위 체계를 만들었습니다.

Outcome

운영 현황을 확인하기 위한 화면 이동 수를 줄이고, 팀 간 공유 기준을 통일했습니다.
