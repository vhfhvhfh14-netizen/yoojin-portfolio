광고·구독 UX 개선

위젯 저장 시, 광고와 구독을 보여주는 방식을 바꿔, 위젯 저장 완수율과 구독률을 높이는 작업을 진행했어요. 저는 이 프로젝트에서 UX/UI 디자인과 테스트를 주도했어요.

Background 이미지 플레이스홀더

Background

낮은 위젯 저장 완수율로 인해 광고·구독 수익을 기대하기 어려웠다

포토위젯의 주요 수익원은 광고와 구독이에요. 그중 위젯 편집 화면은 서비스에서 사용 비중이 높아, 광고·구독 수익에 대한 기대가 컸어요. 이 수익은 위젯을 저장할 때 발생하는데, 정작 저장완수율은 18%에 불과했어요. 즉 비즈니스 측면에서 큰 문제라이를 개선할 여지가 높고 그에 따른 수익 효과가 클 거라 봤어요. 따라서 저장완수율을 높여 광고 구독 수익을 늘리는 것을 목표로 이 프로젝트를 시작했어요.

Problem Definition 이미지 플레이스홀더

Analysis

대부분의 사용자들은 위젯을 만들고도, 저장하지 않고 이탈했다

위젯 편집 화면의 평균 체류 시간은 3분 24초로, 이는 사용자가 위젯을 만드느라 머문 시간으로 해석할 수 있어요. 그런데도 저장 완수율이 낮다는 것은 위젯을 만들고도 저장하지 않는다는 뜻이고, 이를 통해 저장 과정에 문제가 있다고 봤어요. 그래서 저장 시 광고·구독 플로우를 분석해 두 가지 가설을 세웠어요.

Problem 이미지 플레이스홀더

Problem 01

저장 시 광고가 예고 없이 떠, 광고 시청에 대한 거부감을 키웠을 것이다

저장 시 광고에 대한 불만이 전체 CS의 30%를 차지할 만큼 거부감이 컸어요. 이런 상황에서 기존 저장 플로우는 버튼을 누르는 즉시 전면 광고를 띄워, 사용자의 저장 흐름을 끊고 있었어요. 이로 인해 광고에 대한 거부감이 더 커졌을 거라 생각했어요.

Problem 이미지 플레이스홀더

Problem 02

구독하면 광고 없이 저장할 수 있지만, 사용자는 몰랐을 것이다

구독하면 광고 없이 저장할 수 있었지만, 저장 과정에 구독으로 가는 경로가 없어 사용자는 광고 외에 다른 선택지가 있다는 걸 알 수 없었어요.

두 가설을 바탕으로, 광고에 대한 거부감을 낮추고 구독 경로를 열어 저장 완수율을 높이기 위한 실험을 진행했어요.

First Test

광고·구독 인지 시점을 빨리 준다면?

개선 방식: 위젯 만들기 화면에 광고·구독 저장 버튼 노출하기

결과: 저장 완수율·체류 시간은 줄고, 구독 클릭은 5% 미만

원인: 너무 빨리 인지시켜 이탈했고, 구독 혜택은 알 수 없었다

  1. 들어오자마자 '광고'라는 말이 보여, 광고가 싫은 사용자는 시작부터 부담을 느꼈다고 봤어요.
  2. 주 사용자는 구매력이 낮은 10대 학생이라 혜택이 명확해야 구매하는 경우가 많은데, 구독 혜택을 전혀 알 수 없었어요.

Second Test

저장완수를 가장 하고싶을 때 노출하면?

개선 방식: 저장 버튼 클릭 시, 광고·구독 버튼과 구독 혜택 노출하기

결과: 저장 완수율 약 1.6배 상승, 구독은 큰 변화 없음

다음 액션: 개선된 저장 완수율을 가드레일 삼아, 구독 늘리기

구독도 광고만큼 중요해요. 광고 없이 저장하기 때문에 완수율이 높거든요. 그래서 개선된 저장 완수율은 지키면서, 구독을 자연스럽게 늘릴 방법을 테스트하고자 했어요.

A/B Test

혜택은 ‘많이’보다, ‘상황에 맞게 보여줄 때’ 반응했다

테스트 목표: 혜택을 어떻게 보여줘야 구독을 더 고를까

  1. A: Bottom Sheet — 바로 누릴 혜택만 보여주기 (채택 ✓)구독시 당장 누릴 수 있는 혜택을 버튼에 표시했어요. 두번째 테스트 대비 완수율 12%, 구독률 6% 상승했어요.
  2. B: Full View — 구독 혜택 전체를 보여주기광고 없이 저장을 포함한 모든 구독 혜택까지 노출했어요. 두번째 테스트 대비 완수율·구독률 변화가 없었어요.

다음 액션: 개선된 저장 완수율을 가드레일 삼아, 구독 늘리기

사용자는 구독 혜택을 전부 보여준 화면보다, 저장하는 순간에 필요한 혜택 하나를 보여줄 때 더 많이 구독했어요. 그래서 A를 최종 저장 UX로 채택했어요.

  • As Is 대비 저장 완수율 약 2.1배 상승

  • As Is 대비 구독률 약 1.4배 상승

  • 저장 시 광고 관련 CS 월 30건 → 8건

    광고 저장 CS가 줄어 QA 팀이 만족했어요.

Lesson Learn

언제·어떻게 보여주느냐에 따라 경험이 달라진다

불편한 요소는 없애야만 줄어드는 게 아니라, 사용자 경험을 해치지 않도록 ‘언제, 어떤 맥락으로 UX를 설계하냐’에 따라 해소될 수 있다는 걸 배웠어요.

실패한 실험도 유의미하다

실패한 실험 안을 통해 얻은 인사이트는 다음 실험을 설계하는 중요한 근거로 활용됐어요. 이를 통해 실패를 분석해 다음으로 이어가는 과정의 중요성을 배웠어요.
