저장 완수율을 높이기 위한 광고·구독 UX 개선

위젯 저장 시, 광고와 구독을 보여주는 방식을 바꿔, 위젯 저장 완수율과 구독률을 높이는 작업을 진행했어요. 저는 이 프로젝트에서 UX/UI 디자인과 테스트를 주도했어요.

Period
2026.02 – 08
Platform
iOS
Team
기획 1, 디자인 1, iOS 개발 1, QA 1

UX/UI 디자인 100%, 기획 30%
Background — 위젯 저장 시 나오는 광고에 대한 불만 CS 이미지 플레이스홀더

Background

위젯을 만들고도, 저장하지 않고 나가는 사용자들

포토위젯의 메인 BM인 광고와 구독은 위젯을 저장하는 순간에 일어나요. 하지만 위젯 만들기 화면에서 저장하지 않고 나가는 사용자가 많았어요. 이는 사용자 경험뿐 아니라 비즈니스에도 큰 문제였어요.

저장 시, 광고 시청에 대한 거부감이 크다
마침 QA팀에서 '저장 시 광고 때문에 저장하기 싫다'라는 CS가 많이 들어온다고 전해주셨어요. 그래서 저장할 때 광고와 구독이 나오는 과정을 들여다봤어요.

Problem — As Is Flow (10초 인터스티셜 광고 시청) 이미지 플레이스홀더

Problem

광고는 인지할 여유 없이 떴고, 구독하면 광고 없이 저장할 수 있다는 건 알 수 없었다

  1. 광고를 인지할 여유 없이 떠, 거부감을 키웠을 것이다저장 버튼을 누르자마자 광고를 인지할 여유도 없이 떴어요. 이러한 방식 때문에 저장에 대한 불만 리뷰가 많았을거라 생각했어요.
  2. 구독 시 광고 없이 저장할 수 있지만, 사용자는 알 수 없었다위젯 만들기는 구독하면 광고 없이 저장할 수 있어요. 하지만 저장 과정에서 이를 보여주지 않아, 사용자는 광고 말고 다른 방법이 있다는 걸 알 수 없어요.

가설: 저장 시 광고 인지 시점을 주고, 구독 경로를 열어준다면 저장 완수율이 높아질 것이다

First Test 이미지 플레이스홀더

First Test

저장 완수율·체류 시간은 줄고, 구독 클릭은 5% 미만

개선 방식
위젯 만들기 화면에 광고·구독 저장 버튼 노출하기 (의도: 처음부터 광고·구독 인지시키기)

원인: 너무 빨리 인지시켜 이탈했고, 구독 혜택은 알 수 없었다
들어오자마자 '광고'라는 말이 보여, 광고가 싫은 사용자는 시작부터 부담을 느꼈다고 봤어요.

주 사용자는 구매력이 낮은 10대 학생이라 혜택이 명확해야 구매하는 경우가 많은데, 구독 혜택을 전혀 알 수 없었어요.

Second Test 이미지 플레이스홀더

Second Test

저장 완수율 약 1.6배 상승, 구독은 큰 변화 없음

개선 방식
저장 버튼 클릭 시, 광고·구독 버튼과 구독 혜택 노출하기 (의도: 다 만든 후에 광고·구독 인지시키기)

다음 액션: 개선된 저장 완수율을 가드레일 삼아, 구독 늘리기
구독도 광고만큼 중요해요. 광고 없이 저장하기 때문에 완수율이 높거든요. 그래서 개선된 저장 완수율은 지키면서, 구독을 자연스럽게 늘릴 방법을 테스트하고자 했어요.

A/B Test — A: Bottom Sheet / B: Full View 이미지 플레이스홀더

A/B Test

혜택은 ‘많이’보다, ‘상황에 맞게 보여줄 때’ 반응했다

테스트 목표
혜택을 어떻게 보여줘야 구독을 더 고를까

  1. A: Bottom Sheet — 바로 누릴 혜택만 보여주기 (채택 ✓)구독시 당장 누릴 수 있는 혜택을 버튼에 표시했어요. 두번째 테스트 대비 완수율 12%, 구독률 6% 상승했어요.
  2. B: Full View — 구독 혜택 전체를 보여주기광고 없이 저장을 포함한 모든 구독 혜택까지 노출했어요. 두번째 테스트 대비 완수율·구독률 변화가 없었어요.

사용자는 구독 혜택을 전부 보여준 화면보다, 저장하는 순간에 필요한 혜택 하나를 보여줄 때 더 많이 구독했어요. 그래서 A를 최종 저장 UX로 채택했어요.

Results

As Is 대비 저장 완수율 약 2.1배, 구독률 약 1.4배 상승

  • As Is 대비 저장 완수율 약 2.1배 상승

  • As Is 대비 구독률 약 1.4배 상승

  • 저장 시 광고 관련 CS 월 30건 → 8건

    광고 저장 CS가 줄어 QA 팀이 만족했어요.

Lesson Learn

언제·어떻게 보여주느냐에 따라 경험이 달라진다

불편한 요소는 없애야만 줄어드는 게 아니라, 사용자 경험을 해치지 않도록 ‘언제, 어떤 맥락으로 UX를 설계하냐’에 따라 해소될 수 있다는 걸 배웠어요.

실패한 실험도 유의미하다
실패한 실험 안을 통해 얻은 인사이트는 다음 실험을 설계하는 중요한 근거로 활용됐어요. 이를 통해 실패를 분석해 다음으로 이어가는 과정의 중요성을 배웠어요.
