위젯 편집 화면 개편

포토위젯은 6년간 서비스를 운영하며 다양한 위젯 기능을 추가해 왔어요. 이 과정에서 복잡해진 위젯 편집 화면을 V2로 전면 개편해 기존 레거시를 정리하고, 새로운 구조에 맞춰 편집 UX를 재설계했어요.

저는 프로젝트에서 기존 기능과 UX 문제 분석, UX/UI 재설계, 마이그레이션 UX 설계 및 개발 협업을 주도했어요.

Background 이미지 플레이스홀더

Background

위젯 편집 화면은 수년간 쌓인 레거시로 인해, 더 나은 사용자 경험을 제공하기 어려웠다

포토위젯에서 위젯 편집은 사용자가 직접 위젯을 만들고 꾸미는 핵심 기능이에요.

하지만 수년간 새로운 위젯 기능이 추가되는 동안 편집 구조는 충분히 정비되지 않았어요. 그 결과 위젯 편집 과정이 복잡해 레거시 기능이 누적되면서 사용성이 떨어지고 더이상의 기능 확장에 한계가 있었어요. 이에 팀에서는 단순한 기능 개선만으로는 이를 극복하기 어렵다는 공감대가 형성됐어요. 따라서 V2로 재구축하는 편이 장기적인 유지보수와 기능 확장에 더 유리하다고 판단해 개편을 결정했어요.

Problem Definition 이미지 플레이스홀더

Research

정성적 데이터 기반 인사이트 도출

저는 화면 설계를 맡았고, V1 구조를 따르기보다 기존 화면의 문제를 분석해 함께 개선하고자 했어요. 당시 사용자 행동을 확인할 수 있는 정량 데이터가 없어, 신규 입사 시 작성하는 기능 문제점 분석 자료를 바탕으로 기존 사용 흐름과 구조를 검토했어요.

Problem 이미지 플레이스홀더

Problem 01

위젯 타입 변경 시 불필요한 화면 이동이 많다

V1에는 위젯 타입 선택과 세부 편집 화면이 분리되어 있었어요. 이로 인해 사용자가 편집 중 다른 타입으로 변경하려면 편집 화면에서 나간 후 → 재선택하고 → 다시 편집 화면으로 진입하는 번거로움이 있었어요.

Problem 이미지 플레이스홀더

Problem 02

편집 화면에서 본 위젯과 실제 설치된 모습이 달랐다

홈 화면과 잠금 화면은 각각 OS 기능 정책이 달라요. 하지만 V1에선 지원 속성이 다른 두 위젯이 하나의 편집 구조에 묶여 있어,작동하지 않는 기능들이 혼재됐어요. 이로 인해 편집 프리뷰와 실제 설치 결과가 달라지는 문제가 있었어요.

Goal: 이를 해결하고자 불필요한 화면 이동을 줄이고 실제 OS 기능 정책을 반영한 편집 화면으로 설계하고자 했어요.

Solution 이미지 플레이스홀더

Solution

홈·잠금 위젯 편집 화면 분리

V2에서는 홈·잠금 위젯마다 실제로 적용되는 설정만 보여줄 방법이 필요했어요. 이를 위해 홈 위젯과 잠금 위젯 편집 화면을 나누는 안을 검토했고, 개발팀과 논의하며 향후 OS 정책 변화와 신규 위젯 추가에도 대응하기 좋다고 봤어요.

이에 두 개의 별도 편집 화면을 구성하고, 각 화면에서 지원하는 OS 기능을 다시 확인해 반영했어요. 그 결과 V1에서 발생했던 앱 내 프리뷰와 설치 시 위젯 모습의 불일치를 해결할 수 있었어요.

Solution 이미지 플레이스홀더

Solution

홈 위젯 편집 구조 개편

V1에서는 위젯 타입을 바꾸려면 편집 화면을 나간 후 재진입해야 했어요. 이를 개선하기 위해 V2에서는 편집 화면 안에서 타입을 변경할 수 있도록 했어요. 그런데 V1의 편집 방식을 그대로 적용하면, 위젯 타입 변경 시 이미 커스텀한 배경까지 함께 바뀌는 문제가 있었어요. 이에 배경과 위젯 디자인을 각각 독립적으로 편집할 수 있도록 Background와 Custom 레이어로 분리했어요. 이를 통해 배경설정은 유지하면서 위젯 스타일을 변경할 수 있도록 했어요.

Migration 이미지 플레이스홀더

Migration

v1 위젯 모델과의 호환성을 위한 싱글/듀얼 모드

기존에는 하나의 위젯 스타일에서도 M 사이즈에만 다른 디자인이 적용되는 경우가 있었어요. 이로 인해 편집 기능을 일괄적으로 적용하기 어려워 확장성에 한계가 있었어요. 이를 해결하고자 모든 위젯 사이즈에 동일한 디자인을 적용하려 했지만, 전체 위젯 스타일의 약 1/3에서 기존 디자인이 달라지는 문제가 있었어요.

이는 업데이트 시 사용자에게 혼란을 줄 수 있어, V1 위젯 디자인과의 호환성을 유지하면서 구조를 개선할 방법을 고민했어요.

이에 기존 M 사이즈의 좌우 분할 구조를 활용해 싱글/듀얼 모드를 설계했어요. 듀얼 모드에서는 왼쪽에 기본 디자인을 유지하고 오른쪽은 개별 선택할 수 있도록 해, 기존 디자인과의 호환성과 커스텀 자유도를 함께 확보했어요.

Outcome

V2 출시 이후 위젯 작동 관련 CS가 감소했고, 새로운 편집 구조를 기반으로 기능을 확장했습니다

  • 위젯 작동 관련 CS 월 약 30건 → 10건 미만

    V2 출시 이후 위젯 작동과 관련된 월간 CS가 약 30건에서 10건 미만으로 감소했습니다.

  • 출시 후 사용성 설문 약 60% 긍정 응답

    개편 이후 진행한 사용성 설문에서 약 60%의 긍정 응답을 확인했습니다.

  • V2 편집 구조 기반 신규 위젯 3종 출시

    개편한 편집 구조를 기반으로 신규 위젯 3종이 출시되었습니다. 이를 통해 V2 구조가 후속 기능 확장에 실제로 쓰일 수 있음을 확인했습니다.
