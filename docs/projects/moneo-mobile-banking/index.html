Project overview

첫 금융 앱을 사용하는 20대를 위해, 복잡한 자산 흐름을 한 화면에서 이해할 수 있도록 설계한 모바일 뱅킹 경험입니다.

Challenge

정보가 많은 금융 서비스를 처음 접하는 사용자는 자신의 자산 상태와 다음 행동을 파악하기 어려웠습니다.

Approach

사용자 인터뷰를 바탕으로 핵심 과업을 송금·소비 확인·목표 관리로 압축하고, 오늘의 상태를 우선 보여주는 홈 구조를 설계했습니다.

Outcome

프로토타입 사용성 테스트에서 잔액과 다음 행동을 찾는 과업 성공률이 개선되었습니다.
