위젯 탭으로 리뉴얼하여 위젯
만들기 진입률 개선

포토위젯의 핵심 경험인 위젯 만들기 화면 진입 상승을 위해 제작 탭을 위젯 탭으로 리뉴얼했어요. 저는 이 프로젝트에서 기획, UX/UI 디자인을 주도하였고, 개발부터 배포 스케줄 매니징을 했어요.

Period
2026.04 – 08
Platform
iOS
Team
디자인 1, iOS 개발 1, QA 1
Role
UX/UI 디자인 100%, 기획 100%

Problem Definition

현재 제작 탭은 위젯 제작을 유도하지 못했다

3월 위젯 만들기 화면을 개편하면서, 위젯 제작을 유도하기 위한 별도의 공간으로 ‘제작 탭’을 함께 출시했어요. 그러나 출시 후 데이터를 확인한 결과, 제작 탭 진입률은 GNB 기준 5.8%에 그쳤고, 탭에 진입한 사용자 중 60%는 위젯 만들기 화면으로 이동하지 않았어요. 이를 통해 제작 탭으로의 유입이 적을 뿐 아니라, 탭 내에서도 위젯 제작을 충분히 유도하지 못해 출시 의도만큼 활용되지 않고 있음을 확인했어요.

KPI

제작 탭 진입을 유도해 위젯 제작으로 이어지게 한다

앞서 확인한 문제를 바탕으로 두 가지 KPI를 설정했어요. 첫 번째는 제작 탭 진입률을 높여 위젯 제작으로 이어질 수 있는 사용자 모수를 확대하는 것, 두 번째는 탭에 진입한 사용자가 위젯 제작을 시작하도록 유도해 편집 화면 진입률을 높이는 것이에요.

UX Strategy

사용자의 탭 진입 목적에 맞춰 제작 탭을 재구성해 위젯 만들기 유도하기

기존 제작 탭은 여러 기능의 진입점만 제공해, 위젯 제작을 충분히 유도하지 못했어요. 이를 해결하기 위해 제작 탭에 진입하는 사용자 시나리오를 두 유형으로 구분하고, 각 경험에 필요한 기능을 제공하고자 했어요.
하나는 위젯을 만들러 온 사용자가 편집 화면에 바로 진입하도록 하는 것, 다른 하나는 제작 탭을 둘러보는 사용자가 위젯 콘텐츠를 발견하고, 이를 통해 위젯 만들기를 시작하도록 하는 것이에요.

Initial Design Approach

기존 기능의 접근성을 유지하며 위젯을 중점으로 화면 설계

기존 제작 탭에는 위젯을 만들러 온 사용자뿐 아니라 다른 기능을 이용하기 위해 진입하는 사용자도 있었어요. 따라서 기존 기능의 접근성을 유지하면서 위젯 만들기를 중심으로 화면을 설계했어요.

  1. 위젯 만들기 진입점을 화면 최상단에 배치해 핵심 기능 강조
  2. 다른 기능의 진입점은 그대로 제공하되, 숏컷으로 축소해 시각적 위계 조정
  3. 예시 템플릿을 제공해 콘텐츠 탐색을 통한 위젯 만들기 유도

Usability Test

탬플릿은 긍정적이였지만, 제작 진입점이 잘 보이지 않았다

개선한 제작 탭이 위젯 만들기를 유도할 수 있는지 확인하기 위해 UT를 진행했어요. 템플릿에 대한 관심은 긍정적이었지만, 위젯 만들기 진입점을 찾는데 어려움이 있었어요. 또한 기존 사용자를 고려해 유지한 다른 기능의 진입점은 거의 사용하지 않았어요. 여러 기능을 함께 배치한 화면 구성이 오히려 시선을 분산시켜, 위젯 만들기 진입점에 대한 주목도를 낮췄다고 판단했어요.
이를 통해 위젯 제작 유도라는 핵심 목표를 달성하는 데 소수 사용자의 기존 접근성을 유지하는 것이 유의미한지 재검토하게 됐어요.

Solution

위젯 전용 탭으로 리뉴얼: 진입점은 심플하게, 탐색은 한눈에 보이도록

위젯 전용 탭이 핵심 기능 인지에 더 유의미할거라 판단해 과감히 좁혔어요.

  1. 위젯 전용 탭으로 리뉴얼앱 정체성을 강조하고 탭 진입을 유도했어요.
  2. 진입점과 최근에 만든 위젯 노출언제든 만들기 화면에 진입할 수 있게 했어요.
  3. 세로 스크롤 구조로 변경다양한 템플릿 옵션을 노출했어요.

  • 위젯 만들기 진입 사용자 약 1.9배 상승

  • 템플릿으로 시작한 사용자 36%

  • 제작 탭 진입 약 1.3배 상승

Results

언제·어떻게 보여주느냐에 따라 경험이 달라진다

불편한 요소는 없애야만 줄어드는 게 아니라, 사용자 경험을 해치지 않도록 ‘언제, 어떤 맥락으로 UX를 설계하냐’에 따라 해소될 수 있다는 걸 배웠어요.

실패한 실험도 유의미하다

실패한 실험 안을 통해 얻은 인사이트는 다음 실험을 설계하는 중요한 근거로 활용됐어요. 이를 통해 실패를 분석해 다음으로 이어가는 과정의 중요성을 배웠어요.
