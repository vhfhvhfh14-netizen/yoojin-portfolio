Project overview

여행 계획을 함께 만드는 과정이 흩어지지 않도록, 영감부터 일정 확정까지 연결한 협업형 웹 서비스입니다.

Challenge

여행 동행자들이 링크와 메신저에 흩어진 정보를 모으고 합의하는 데 많은 시간을 사용했습니다.

Approach

저장·비교·투표라는 세 가지 행동을 하나의 여정 안에 배치해 계획의 맥락이 이어지도록 했습니다.

Outcome

테스트 참가자들이 기존 방식보다 더 적은 메시지로 일정을 확정할 수 있었습니다.
